# Contributing

Use English for documentation and reports.

- **Before opening an issue:** collect the ASUS board/model, firmware, macOS build, OpenCore version, affected device IDs, exact kext versions and last change. Describe reproduction steps and actual results. Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- **What to share:** relevant redacted excerpts only.
- **What never to share:** SMBIOS identities, network credentials, device addresses, complete system reports or firmware dumps.
- **Configuration changes:** name the affected hardware and dependencies, link upstream references and separate configuration checks from hardware tests. Use the [pull request template](.github/pull_request_template.md).
- **Attribution:** keep upstream credits and version limits for binary patches. New original contributions use MIT; see [License scope](NOTICE.md) for third-party material.
